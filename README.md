# Evera Gold — Responsive Jewellery Landing Page

A premium-style fictional jewellery brand landing page created as an individual UI/UX assignment concept. This repository contains a responsive HTML, CSS, and JavaScript implementation to accompany a Figma design.

## Project details
- **Brand:** Evera Gold
- **Category:** Jewellery / E-commerce concept
- **Target audience:** Fashion-conscious customers, young adults, working professionals, and people shopping for gifts or special occasions.
- **Design direction:** Elegant, minimal, warm, premium.

## Design choices
The visual identity combines luxury black (`#171613`), champagne gold (`#B8914D`), and warm ivory (`#F8F4EC`). Playfair Display gives headings an editorial jewellery-brand feel, while Inter keeps navigation and body copy easy to read. Product cards, category tiles, clear calls to action, and a mobile navigation menu help visitors explore the page.

## Responsive behaviour
The layout uses CSS Grid and Flexbox for the desktop design, with breakpoints that stack the hero, category cards, product cards, benefits, and footer on small screens. The mobile header includes a collapsible navigation menu.

## Components / reusable patterns
1. Primary and outline buttons
2. Product cards with favourite buttons
3. Category cards
4. Benefit cards
5. Responsive header and footer

## Files
- `index.html` — page structure and content
- `style.css` — visual styles and responsive breakpoints
- `script.js` — mobile menu, favourites interactions, and demo newsletter form

## Run locally
Open `index.html` in a browser. An internet connection is used for Google Fonts and remote Unsplash demo images.
